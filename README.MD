# Profile Card

A simple, responsive personal profile card built with semantic HTML and CSS.

## About the Project

This project displays a personal profile card containing:

- A profile image
- My name
- A professional headline
- A short introduction
- A skills section
- A contact link

The card is built using semantic HTML, with `<article>` as the main container for the profile information.

## Technologies Used

- HTML5
- CSS3

## Features

- Semantic and accessible HTML structure
- Circular profile image
- Clean card layout
- Rounded corners and subtle shadow
- Centered card design
- Easy-to-customize content and styles

## Project Structure

```text
profile-card/
├── index.html
├── style.css
├── profile.jpg
```

## How to View the Project

1. Download or clone the project folder.
2. Open the folder in your code editor.
3. Open `index.html` in a web browser.

You can also open `index.html` directly by double-clicking it.

## How to Customize

1. Open `index.html`.
2. Replace the name, headline, introduction, skills, and contact link with your own information.
3. Replace `images/profile.jpg` with your own profile photo.
4. Open `style.css` to change colors, fonts, spacing, and card styling.
